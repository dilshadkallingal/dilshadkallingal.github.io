Spancom POS

Offline-first Android point of sale for businesses in the UAE.

Period
Feb 2021 – Oct 2022
Company
Devmonkey Inc
Team
5 developers
Stack
Flutter, Dart, SQLite, Firebase, RxDart, Provider, REST APIs

Spancom POS automates billing and inventory so businesses no longer collect bills by hand. It keeps working without a connection and syncs to the cloud when one is available.

Features

  • Automated transaction processing and billing
  • Inventory synced across locations
  • Full offline operation with SQLite
  • Cloud sync through Firebase
  • REST APIs for integration with existing business systems

My role

  • Designed and built the UI with Flutter and Material Design.
  • Built the sync engine between local SQLite and Firebase.
  • Used RxDart and Provider for asynchronous data flows.
  • Improved load times and transaction speed.
  • Managed sprint backlogs and wrote unit and integration tests.

What I learned

Offline-first architecture, keeping data in sync between SQLite and Firebase, and performance tuning with RxDart and Provider.
