Talkomi

A social app for food lovers, built for Talkomi Inc in the USA.

Period
Feb 2019 – Feb 2021
Company
Talkomi Inc
Team
7 people, distributed globally
Stack
Flutter, Dart, Firebase Realtime Database, Cloud Functions, Provider

Talkomi is a social networking app for food enthusiasts, with real-time updates, media sharing and interactive feeds.

Features

  • Real-time feed updates
  • Media sharing
  • Interactive user feeds
  • Background processing with Cloud Functions
  • Analytics and error monitoring

My role

  • Built the app's features in Flutter for iOS and Android.
  • Integrated Firebase Realtime Database and Cloud Functions for data sync and background processing.
  • Used Provider for state management and optimised animations for a more responsive UI.
  • Added error handling and analytics to monitor app health and user behaviour.
  • Kept the iOS and Android builds at feature parity.
  • Worked in a globally distributed team of seven, using Jira and GitLab.
