Hakeem is a large-scale digital healthcare app for patients across Qatar. It brings appointments, medical records, lab reports and live consultations into one place, built to the privacy standards that healthcare data requires.

Features

  • Appointment booking
  • Health records
  • Lab report downloads as PDF
  • Prescription tracking
  • Live consultations
  • Push notifications through Firebase Cloud Messaging

My role

  • Led development and the production release.
  • Architected the app with Clean Architecture, keeping the domain, data and presentation layers separate.
  • Used Riverpod for scalable state management across the app.
  • Designed secure authentication, token refresh and the API communication layer.
  • Integrated Firebase Analytics and Crashlytics for usage insight and crash monitoring.
  • Ran iOS and Android release cycles with the backend and QA teams through Azure DevOps.
