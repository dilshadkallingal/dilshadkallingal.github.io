ZPOS

Cloud-based point of sale for a UK retail client.

Period
Nov 2023 – Feb 2025
Company
Zensign LLP
Team
5 developers
Stack
Flutter, Dart, Firebase, RxDart, REST APIs

ZPOS is a real-time, cloud-based system that handles billing, inventory and user controls in one interface. It gives store staff live sales and stock data so they can manage transactions and inventory without switching tools.

Features

  • Real-time sales and inventory data
  • Cloud access from any location
  • Sales insights to help optimise performance
  • Configurable to each business's workflow
  • Encrypted data and user access controls

My role

  • Led the technical implementation and architecture.
  • Built the UI with Flutter and Material Design.
  • Implemented real-time inventory sync with Firebase, cutting stock discrepancies by 35%.
  • Optimised the billing flow, making it 40% faster.
  • Used RxDart for reactive state management.
  • Ran code reviews and mentored junior developers.

What I learned

Reactive state management with RxDart, real-time data handling with Firebase, and keeping a five-person agile team aligned on performance and code quality.
